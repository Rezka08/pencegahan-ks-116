# Lingkungan Ramah Anak - KKN-T 116 Desa Batara

## Deskripsi Proyek
Proyek ini merupakan sebuah platform website edukasi dan sosialisasi yang dikembangkan oleh mahasiswa Kuliah Kerja Nyata Tematik (KKN-T) Inovasi Desa Gelombang 116 Universitas Hasanuddin yang berlokasi di Desa Batara. Tujuan utama dari website ini adalah untuk menyebarluaskan informasi mengenai pencegahan kekerasan seksual terhadap anak, serta mengedukasi masyarakat guna mewujudkan lingkungan yang aman dan ramah anak.

## Fitur Utama
- **Edukasi Definisi & Hak Anak**: Penjelasan komprehensif mengenai definisi anak secara hukum dan penjabaran 10 hak dasar anak yang diakui secara nasional maupun internasional.
- **Fakta & Data Kasus**: Pemaparan data darurat kekerasan seksual untuk meningkatkan kesadaran (*awareness*) masyarakat akan pentingnya perlindungan anak.
- **Ragam Bentuk Kekerasan & Hukum**: Edukasi mengenai berbagai jenis pelecehan dan kekerasan seksual, mulai dari fisik, non-fisik, hingga eksploitasi elektronik, beserta sanksi tegas menurut UU TPKS.
- **Panduan Pencegahan Bersama**: Langkah-langkah preventif yang dapat diterapkan oleh orang tua, keluarga, dan masyarakat sekitar untuk membekali anak dalam melindungi dirinya.
- **Pusat Pelaporan Darurat**: Penyediaan akses cepat ke kontak darurat dan layanan pelaporan (seperti SAPA 129) bagi korban atau saksi tindak kekerasan.

## Teknologi yang Digunakan
Website ini dibangun secara ringkas dan modern menggunakan:
- **HTML5**: Sebagai struktur utama halaman.
- **Tailwind CSS**: Digunakan via CDN untuk penyusunan tata letak dan desain responsif yang modern dengan konsep *glassmorphism*.
- **Vanilla JavaScript**: Untuk mengatur interaksi *mobile menu*, animasi *scroll*, dan efek visual (*Intersection Observer*).
- **Font Awesome**: Penyedia grafis ikon interaktif.

## Cara Menjalankan Secara Lokal
Website ini didesain agar mudah diakses tanpa memerlukan konfigurasi sisi server.

1. Lakukan *clone* repositori ke perangkat lokal Anda:
   ```bash
   git clone https://github.com/Rezka08/pencegahan-ks-116.git
   ```
2. Arahkan direktori ke folder proyek:
   ```bash
   cd pencegahan-ks-116
   ```
3. Buka berkas `index.html` menggunakan peramban (browser) standar pilihan Anda, atau gunakan ekstensi seperti Live Server pada kode editor.
